The code that makes the difference

const { deadline } = require('deadline-relay');

app.use(deadline({ timeout: 5000, reserve: 25 }));

app.get('/orders', async (req, res) => {
  // forwards the *remaining* budget and aborts when it runs out
  const r = await req.deadline.fetch('http://inventory/stock');
  res.status(r.status).send(await r.text());
});

app.get('/stock', async (req, res) => {
  // pass the signal to anything cancellable (DB driver, fetch, fs...)
  const rows = await db.query(sql, { signal: req.deadline.signal });
  res.json(rows);
});

Install it with npm install deadline-relay. The full source of this page and its three services is in server.js.

The three services run in one process here (so the demo can be hosted for free) but talk over real HTTP, exactly as separate deployments would.
